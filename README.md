# tohankinki-drill

登録販売者向けの「してはいけないこと」暗記ドリル。

厚生労働省「試験問題の作成に関する手引き（令和8年4月一部改訂）」第5章 別表5-1「主な使用上の注意の記載とその対象成分・薬効群等」のうち「してはいけないこと」全97項目を収録しています。

## 使い方

`index.html`（ホーム）をブラウザで開き、5つのボタンから各ページへ移動します。してはいけないことドリル本体は `kinki.html` です。いずれも開くだけで動きます（ビルド不要、外部依存は Google Fonts のみ）。

- **構成**：ホーム → 3つの大分類（誰に・どんな時ダメ？ 90問／どの成分がダメ？ 97問／なぜダメ？ 96問）→ 12分類 → 1周解いて結果・解き直し
- **12分類**：アレルギー・症状・基礎疾患・透析/口・小児・妊婦授乳・運転・連用・大量/乱用・飲酒/カフェイン・併用・部位
- **まとめて解く**：間違えた問題（形式そのまま）／全範囲ランダム20問／大分類ごとのランダム20問
- **復習**：間違えた問題を記録し、「間違えた問題だけ」で再出題
- **BGM**：オリジナルのループ曲をブラウザ内で生成（音源ファイルなし）。画面右上で ON/OFF、別タブに切り替えると自動で止まる
- **効果音**：正解で「ピローン」、不正解で「ブッブー」（Web Audio で生成。ON/OFF 切替可）
- **記録**：累計・今日の回答数、直近14日のグラフ、分野別の正答率、苦手な問題トップ10
- **一覧**：全項目を分野別に表示、キーワード検索可
- キーボード：`1`〜`4` で回答、`Enter` で次の問題

## 成分カード（seibun.html）

手引き第3章「主な医薬品とその作用」から、代表的な成分・生薬・漢方処方 350枚（成分188／生薬84／漢方78）を薬効群ごとにまとめた暗記カード。ホームから開けます。

- 表：名前（漢方は読み付き）／裏：分類・作用（漢方は適応）・主な配合先（漢方はカンゾウ・マオウ・ダイオウの有無）・注意
- 薬効群（Ⅰ-1 かぜ薬〜ⅩⅤ 公衆衛生用薬）と種別（成分／生薬／漢方）で絞り込み
- 出題の向き：「名前→中身」「作用→名前」
- 「覚えた／まだ」を記録して未習得だけ出題、シャッフル
- 一覧・検索タブ（例：「抗コリン」「偽アルドステロン」「15歳未満」）
- 記録は localStorage（キー `tohan-known`、`tohan-pref`）。ドリルの記録とは別に保存
- 文言は手引きをもとにした要約。作用や注意が共通の成分は1枚にまとめている場合あり

## 濫用防止8成分ドリル（ranyou.html）

指定濫用防止医薬品の8成分（エフェドリン、コデイン、ジヒドロコデイン、ジフェンヒドラミン、デキストロメトルファン、プソイドエフェドリン、ブロモバレリル尿素、メチルエフェドリン）と販売ルールの4択クイズ（全64問）。もとは別リポジトリ ranyou8-drill にあったものを、内容はそのままこちらに移した。

- ランダム10問・全問・成分別・販売ルール・間違えた問題の復習、成分カード
- 内容は2026年10月時点の制度（令和8年5月1日施行、令和8年厚生労働省告示第32号）と手引きの記載に基づく
- 記録は localStorage（キー `ranyou8-v1`、`ranyou8-snd`）。他のページの記録とは別に保存

## 禁忌チェッカー（hantei.html）

持病・症状・年齢・妊娠授乳・アレルギー歴・生活（運転・飲酒・連用など）・外用薬を使う部位を選ぶと、手引き第5章 別表5-1「してはいけないこと」・5-2「相談すること」から該当する成分・薬効群を一覧表示する判定ツール。ホームから開けます。

- **持病・属性から探す**：条件を複数選ぶと、該当成分を「使用しないこと／相談すること」に分けて一覧化し、各項目に理由と掲載ページ（p.401〜411）を表示
- 年齢は区分を1つ選ぶと該当する年齢制限（15歳未満・12歳未満・6歳未満・3歳未満・1ヶ月未満・高齢者）をまとめて判定。妊娠は時期（初期／中期以降／予定日12週以内／妊娠希望）で妊婦・12週以内・3ヶ月以内の項目を出し分け
- **成分から探す**：成分名から逆引き。「抗ヒスタミン成分」「抗コリン成分」「アドレナリン作動成分」等の分類名で書かれた項目も拾う
- **飲み合わせ**：薬・飲食を2つ以上選ぶと併用の注意を表示。別表の併用・飲酒・カフェイン飲料の項目に、第3章各薬効群の【相互作用】の記載を加えている（第3章由来は「併用に注意」として区別）
- 結合セルの解釈は禁忌ドリルと同じ。加えて、外用鎮痛消炎薬（インドメタシン等）はアレルギー既往歴の項目にも含め、5-2の「急性のはげしい下痢」は収斂成分の止瀉薬とロペラミド、「発熱を伴う下痢・血便」はロペラミドとして扱っています
- 記録は保存しません（開くたびに初期状態）

## 成分分類表（bunrui.html）

手引き第3章「主な医薬品とその作用」を、薬効群 → 成分の分類（抗ヒスタミン成分・制酸成分など）→ 成分名・はたらき・主な注意点 の表にまとめた早見表。問題形式ではなく、引いて確認する用。35薬効群・185分類・506行（漢方処方製剤を含む）。

- **薬効群から見る**：左の索引（スマホでは選択欄）から薬効群を選ぶと、分類ごとの表を表示。分類名のチップでその表へ移動
- **分類から横断**：2つ以上の薬効群に出てくる分類（例：抗ヒスタミン成分は9群）を選ぶと、その分類の表を薬効群をまたいでまとめて表示
- **検索**：成分名・分類名・効能・注意点を横断検索（例：「緑内障」「カンゾウ」「15歳未満」）。一致箇所を強調
- 「注意点」のチェックで注意点列の表示を切り替え。「使用を避ける」などの言い回しは下線で強調
- 選んだ薬効群・表示設定は localStorage（キー `tohan-group`、`tohan-mode`、`tohan-cat`、`tohan-caution`）に保存
- 文言は手引きをもとにした要約。ⅩⅥ 一般用検査薬は成分分類がないため未収録

## ページ構成

- `index.html`：ホーム（5ページへのボタンだけ）

## 記録の保存先

記録はブラウザの localStorage（キー `shiteha-record`）に保存されます。同じ端末・同じブラウザなら閉じても残りますが、サイトデータを消すと消えます。別の端末へ移すときは「記録」タブの「記録を書き出す」で JSON を保存し、移した先で「記録を読み込む」を使ってください。

## データについて

- 理由の文言は手引きの記載どおり。各項目に掲載ページ（p.401〜406）を付けています。
- 結合セルの解釈：カフェイン主薬の眠気防止薬は「心臓病」「胃潰瘍」の両方、インドメタシン等の外用鎮痛消炎薬は「喘息を起こしたことがある人」、「患部が化膿している人」と「水痘・みずむし等の部位」は同一の条件として扱っています。
- 手引き原文の「クエン酸チペビジン」は誤植とみなし「チペピジン」に修正しています。
